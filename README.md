# Threads Studio

내 Mac에서 돌아가는 Threads 글 작성·발행 도구. 트렌드 소재 → 페르소나로 2~3줄 글 생성(Claude) → 쿠팡 파트너스 링크 + 공정위 문구 → Threads 즉시 발행/예약 → 반응 분석.

## 실행 (Mac)

1. 이 저장소를 내려받기: GitHub 페이지에서 **Code → Download ZIP** 후 압축 해제 (또는 `git clone`)
2. 폴더 안의 `run.sh`를 더블클릭하거나, 터미널에서:
   ```bash
   cd threads-studio
   ./run.sh
   ```
   처음 한 번은 필요한 패키지를 설치하느라 30초쯤 걸려요. 그다음부터는 바로 브라우저가 열려요 (`http://127.0.0.1:8787`).
3. **설정** 탭에서 키를 넣고 저장:
   - Claude API 키 (글 생성)
   - Threads 장기 액세스 토큰 (쿠팡용 새 계정의 토큰)
   - 쿠팡 파트너스 Access/Secret Key — 나중에 발급되면. 없어도 링크를 직접 붙여넣어 쓸 수 있어요.
   - 네이버 데이터랩 키 — 선택

`run.sh` 더블클릭이 안 되면: Finder에서 우클릭 → 정보 가져오기 → 다음으로 열기: 터미널. 또는 터미널에서 `chmod +x run.sh` 한 번.

## 탭 설명

| 탭 | 하는 일 |
|---|---|
| 원고 작성 | 소재 + 페르소나 + 톤 고르면 2~3줄 글 여러 개 생성. 수정 → 지금 올리기 / 예약 |
| 제휴(쿠팡) | 상품 검색(API) 또는 직접 입력 → 공정위 문구 자동 삽입 → 링크는 첫 답글로. "직접 써본 경험"을 적은 경우에만 체험 톤 |
| 벤치마킹 | 반응 좋은 글 스크랩(검색 또는 붙여넣기) → 반응도 점수 → 선택해서 "구조·말투" 추출 → 새 페르소나 |
| 트렌드 | Google 트렌드 한국 실시간 키워드(키 불필요), 네이버 데이터랩 검색어 비교(키 필요) |
| 내 스레드 관리 | 예약/발행 기록, 내 글 반응(조회·좋아요·답글·리포스트), Claude 계정 분석 리포트 |
| 페르소나 | 기본 4종 + 직접 만들기/수정 |
| 설정 | 키 연동 |

## 이 프로그램이 지키는 것

- **가짜 후기 금지.** 안 써본 상품을 써본 것처럼 쓰지 않아요. 소개형("이런 게 있더라")으로 쓰고, 직접 써본 경험을 적은 경우에만 체험 톤으로 써요.
- **공정위 표시 문구는 본문 맨 앞.** 답글에만 두면 불충분해요.
- **링크는 첫 답글에.** 본문 링크는 도달이 줄어요.
- **벤치마킹은 베끼기가 아님.** 구조와 말투를 배우고, 문장은 새로 써요.

## 계정 안전 수칙 (프로그램이 대신 못 해주는 것)

- 새 계정은 하루 2~3개부터. 많아도 5개.
- 예약 시간은 아침·점심·저녁에 흩어두고 분 단위를 00/15/30/45로 맞추지 마세요.
- 제휴 글만 올리지 말고 일상 글을 더 많이. 제휴 글은 전체의 1/3 이하.
- 매일 몇 분은 직접 다른 글에 좋아요·답글. 답글 달리면 답하기.
- 예약 글은 **이 프로그램이 켜져 있을 때만** 나가요. Mac 잠자기를 꺼두거나, 예약 대신 즉시 발행을 쓰세요.

## Threads 토큰 받기 (새 계정)

Meta 개발자 → 기존 앱(Access the Threads API) → 앱 역할 → 역할 → **사람 추가 → Threads 테스터**로 새 계정 추가 → 그 계정의 Threads 앱에서 설정 → 웹사이트 권한 → 초대 수락 → 이용 사례 → Threads API 액세스 → 설정 → 사용자 토큰 생성기에서 토큰 생성.
권한은 `threads_basic`, `threads_content_publish`, `threads_manage_insights`(반응 조회), `threads_keyword_search`(벤치마킹 검색, 선택)를 켜두세요.

## 데이터
