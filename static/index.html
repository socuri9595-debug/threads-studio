간편 글 작성

트렌드 탭에서 키워드를 고르면 여기 들어와요.

생성된 글은 오른쪽에 떠요. 수정하고 바로 올리거나 예약할 수 있어요.

왼쪽에서 소재와 페르소나를 고르고 글 생성을 누르세요.

상품 고르기

쿠팡 파트너스 API 키가 없으면 아래에 상품 정보를 직접 넣어요. 파트너스 사이트에서 '링크 생성'으로 만든 링크를 붙여넣으세요.

글 만들기

안 써본 상품을 "이런 게 있더라" 톤으로 소개해요. 가장 안전한 기본값.
공정위 표시 문구는 글 맨 앞에 자동으로 들어가요. 링크는 첫 답글로 달려요. 이 두 가지는 끄지 않는 걸 권해요.
상품을 고르고 소재를 적은 뒤 생성하세요.

글 스크랩

반응 좋은 글을 모아두고, 선택해서 '어떤 구조와 말투가 먹히는지'를 뽑아 내 페르소나로 만들어요. 문장을 베끼지는 않아요.

보관함

쇼핑 인기 검색어 (네이버 데이터랩 쇼핑인사이트 · 최근 7일)

요즘 사람들이 사려고 검색하는 것. 카테고리를 누르면 TOP 20이 떠요. 키워드를 누르면 제휴 탭의 상품명·소재로 들어가요.

Google 트렌드 (한국, 실시간 — 뉴스·이슈 위주)

키워드를 누르면 원고 작성 탭의 소재로 들어가요.

네이버 데이터랩 검색어 비교 (최근 30일)

설정에 네이버 API 키가 있어야 해요. 없으면 Google 트렌드만 써도 돼요.

예약 / 발행 기록

내 게시물 (최근 25개 + 반응)

연동

키는 이 컴퓨터의 data/settings.json에만 저장돼요. 빈 칸으로 저장하면 기존 값이 유지돼요.

이 프로그램이 지키는 것

  • 안 써본 상품을 써본 것처럼 쓰지 않아요. 남의 후기는 "후기 보니까 ~래"로 출처를 밝혀 종합하고, '직접 써봄'을 고른 경우에만 체험 톤으로 써요.
  • 제휴 글은 공정위 표시 문구가 본문 맨 앞에 들어가요.
  • 글 본문에 링크를 넣지 않고 첫 답글에 달아요. (본문 링크는 도달이 줄어요)
  • 하루에 많이 올리지 마세요. 새 계정은 하루 2~3개부터. 예약 시간은 분 단위를 흩어두세요.
  • 벤치마킹은 구조·말투를 배우는 용도예요. 남의 문장을 그대로 쓰지 않아요.
이 프로그램은 컴퓨터에서 실행 중일 때만 예약 글이 나가요. 예약을 걸어뒀으면 Mac을 켜두세요(잠자기 해제).
